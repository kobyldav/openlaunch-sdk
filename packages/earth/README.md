# @openlaunch/earth (v1.1.0)

Copernicus, STAC, Planetary Computer, Open-Meteo and EO catalog metadata. Install only the capabilities your application needs:

```sh
npm install @openlaunch/earth
```

```ts
import { EarthCatalogClient, bbox } from '@openlaunch/earth';
```

Use `const sdk=new EarthCatalogClient(); const scenes=await sdk.discoverObservations({area:bbox(12,49,13,50),from:new Date("2026-09-01"),to:new Date()});`.

No satellite.js dependency. Raster decoding is in @openlaunch/raster. Existing all-in-one EarthIntelligenceClient remains in openlaunch-sdk for compatibility.

**Distribution:** generated by the monorepo build into `dist/esm`, `dist/cjs` and `dist/types`. Root `openlaunch-sdk` v1.1 remains the backwards-compatible umbrella package. Internal module subpaths are implementation details and not intended as stable public APIs.

Source: [kobyldav/openlaunch-sdk](https://github.com/kobyldav/openlaunch-sdk). MIT license. Flight/orbit calculations are research-grade, not safety qualified.
