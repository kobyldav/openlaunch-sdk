# Changelog

## 0.1.0 - 2026-09-26

- Initial TypeScript SDK.
- Launch Library 2 v2.3.0 client.
- Normalized launches, rockets, agencies, astronauts, events and launch pads.
- Generic accessors for spacecraft, stations, celestial bodies, docking events, expeditions, payloads and programs.
- Built-in memory cache, retry/backoff, token authentication and raw escape hatch.
- Countdown/live/webcast helpers.
- ESM + CommonJS builds and type declarations.
